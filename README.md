# cc-quarantine-lab

CC_Codex 二期（26.11）**数据工程**产品线：**抓取隔离舱检疫台**（Pyramid + Waitress + 原生 JS SPA 右侧抽屉 + SQLite）。

## 一句话骨架

**抓取批次 → 坏件入隔离舱 → 复核放行 / 回炉重抓 → 隔离对账**

与血缘影响、压实合并、回灌切片、契约换版、水印盖印、清单闭合、留存裁撤**正交**；不做 CDC 游标 / Feed 归并 / Slicegate 类指纹。

## 领域

- **所属领域**：数据工程
- **子方向偏采集**：源站抓取结果检疫、坏件隔离、回炉重抓、隔离对账

## 页面（≥9）

1. 抓取批次 2. 隔离舱 3. 复核放行 4. 回炉队列 5. 隔离对账  
6. 源站名册 7. 入舱规则 8. 审计轨迹 9. 去重账册 10. 台参数

## 抓取去重（独立账册）

- **形态**：甲侧独立账册。入舱与去重记账**同一笔事务**，先取写锁串行化；抓取侧只读引用账册，不改写。
- **账册**：`dedupe_ledger`。`已落舱` 记源件键、当刻源件指纹与落点隔离行（同一源件键全库仅一笔）；
  `拒重` 记同源件重复抓取时的撞件指纹与所属落点。
- **入舱**：同源件已有落点即拒绝二次入舱（409），本笔只落拒重，绝不新增隔离行；徽标、撞件次数、
  落点行任一拧花即拒重入舱。
- **回炉**：重试列表逐条联验去重徽标 / 撞件次数 / 去重落点 / 指纹；无落点行、无账册、指纹对不上都拒绝执行。
- **只读口径**：台参数页只读展示去重形态，不可切换；无切流 / 双写两轨并行面。
- **页面**：抓取批次列撞件次数、条目详情列去重徽标/撞件次数/去重落点；隔离舱卡片旁挂指纹条；
  回炉队列亮徽标与撞件次数；去重账册页列全部落点与撞件。
